# Getting Help

Stuck? That is normal, and asking is how learning works here. **No question is too basic.**

| I need help with... | Best place |
|---|---|
| **A concept or an exercise** | The track channel (link shared by the core team), or a [question issue](https://github.com/GDG-TUM/AI-ML-Track-GDG-on-Campus-TUM/issues/new/choose) |
| **Setting up my laptop or Colab** | The track channel, or ask the Track Lead directly |
| **Something broken in this repo** (link, notebook, typo) | A [bug report](https://github.com/GDG-TUM/AI-ML-Track-GDG-on-Campus-TUM/issues/new/choose) |
| **An idea for a session or project** | A [session proposal](https://github.com/GDG-TUM/AI-ML-Track-GDG-on-Campus-TUM/issues/new/choose) or [project proposal](https://github.com/GDG-TUM/AI-ML-Track-GDG-on-Campus-TUM/issues/new/choose) |
| **A security problem or a leaked key** | **Not a public issue.** See [SECURITY.md](SECURITY.md) |
| **A conduct concern** | [gdgtum@gmail.com](mailto:gdgtum@gmail.com), see the [Code of Conduct](CODE_OF_CONDUCT.md) |
| **Anything else** | [gdgtum@gmail.com](mailto:gdgtum@gmail.com) |

## How to ask a good question

You will get faster, better answers if you include:

1. **What you are trying to do** (the goal, not just the error)
2. **What you tried**, and what you expected to happen
3. **What actually happened**, with the full error message
4. **A small example** that shows the problem (a few lines, not your whole project)

Before you post, remove any API keys, tokens and personal data.
