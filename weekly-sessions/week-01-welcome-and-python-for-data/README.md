# Week 1: Welcome and Python for data

**Date:** Wed 14 Oct (draft; confirm time and venue in the track channel)

**Goal:** Understand what machine learning is, and explore a dataset with Python in your browser.

## Learning objectives

By the end you should be able to:

- Explain machine learning in one sentence, and tell AI, ML, deep learning and generative AI apart
- Run a notebook in Colab and save your own copy
- Load, summarise and plot a table with pandas and matplotlib
- Describe how the track works and how to contribute

## Before the session

- [ ] Finish the [Getting Started](../../GETTING-STARTED.md) checklist (GitHub with 2FA, Google account)
- [ ] Skim [Stage 1: Foundations](../../learning-path/01-foundations.md)
- [ ] New to Python? Do the first two [Kaggle Learn Python](https://www.kaggle.com/learn/python) lessons, and tell the Track Lead so we can pair you up

## Agenda

1. Arrive and set up: open Colab, fix login problems (10 min)
2. Welcome and a tour of the track and how we work (10 min)
3. What is machine learning? Rules versus learning, a live demo (15 min)
4. Notebook in pairs: NumPy, pandas, matplotlib (40 min)
5. 🛡️ Responsible AI moment (5 min)
6. Share-out and take-home challenge (10 min)

## 🛡️ Responsible AI moment

Datasets are made by people, about people. **Who is missing from the cafeteria data?** (Students who never buy chai. Days the shop was closed.) Whatever is missing from the data is missing from the model.
