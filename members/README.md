# 👋 Members

Adding yourself here is your **first contribution**. It teaches the whole fork, branch, commit and pull request flow on something safe.

## Steps

1. **Fork** this repository (button at the top right on GitHub)
2. **Clone** your fork:

   ```bash
   git clone https://github.com/<your-username>/AI-ML-Track-GDG-on-Campus-TUM.git
   cd AI-ML-Track-GDG-on-Campus-TUM
   ```

3. **Create a branch:**

   ```bash
   git checkout -b docs/add-profile-<your-username>
   ```

4. **Copy the template** to a new file named after your GitHub username:

   ```bash
   cp members/_template.md members/<your-username>.md
   ```

5. **Fill it in** with your details (share only what you are comfortable making public)
6. **Commit and push:**

   ```bash
   git add members/<your-username>.md
   git commit -m "docs(members): add profile for <your-username>"
   git push origin docs/add-profile-<your-username>
   ```

7. **Open a pull request** on GitHub. Use the title `docs(members): add profile for <your-username>` and fill in the template.
8. A maintainer reviews and merges. Welcome aboard! 🎉

## Rules

- One file per person, named `<github-username>.md`
- Keep the `**GitHub:**` line from the template. A check uses it to match the file to your username.
- Do not share phone numbers, home addresses or anything private
- Keep it friendly and professional
- No photos of other people, and think twice before adding your own
