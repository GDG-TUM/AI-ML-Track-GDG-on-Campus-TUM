# 🎁 Free Resources

Everything here is free, or free to start. **Free tiers, quotas and course terms change**, so check the official page before you rely on one.

## 🌱 Start here

| Resource | Why it helps |
|---|---|
| [Kaggle Learn](https://www.kaggle.com/learn) | Short, hands-on lessons on Python, pandas, ML, deep learning and more, right in the browser |
| [Machine Learning Crash Course (Google)](https://developers.google.com/machine-learning/crash-course) | A clear, visual introduction with exercises |
| [Google Colab](https://colab.research.google.com) | Notebooks in your browser with free compute |
| [Kaggle Notebooks](https://www.kaggle.com/code) | Another free place to run notebooks, next to the datasets |

## 📊 Data

Always check the **licence** and **source**, and avoid personal data. See the [Responsible AI guide](../docs/responsible-ai.md).

| Where | What |
|---|---|
| [Kaggle Datasets](https://www.kaggle.com/datasets) | Huge catalogue with notebooks attached |
| [Hugging Face Datasets](https://huggingface.co/datasets) | Text, audio and image datasets |
| [UCI Machine Learning Repository](https://archive.ics.uci.edu) | Classic small datasets, ideal for learning |
| [Google Dataset Search](https://datasetsearch.research.google.com) | Find datasets across the web |
| [Common Voice](https://commonvoice.mozilla.org) | Public voice data in many languages, including Swahili |

## 🎓 Certifications

Certificates are optional and no substitute for projects, but they can help with internships and jobs. Check each provider's **current** exam guides and costs.

- [Google Cloud certifications](https://cloud.google.com/learn/certification): including a Professional Machine Learning Engineer path
- [Google Skills (Cloud Skills Boost)](https://www.skills.google/): free labs and learning paths on ML and generative AI
- [Kaggle Learn](https://www.kaggle.com/learn): free completion certificates for its courses
- The [Cloud Track](https://github.com/GDG-TUM/Cloud-Track-GDG-on-Campus-TUM) lists cloud certifications and how to prepare
