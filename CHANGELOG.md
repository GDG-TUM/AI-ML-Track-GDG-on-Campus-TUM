# Changelog

All notable changes to this repository are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/) as described below.

**What the version numbers mean for a curriculum repo**

- **MAJOR** (`2.0.0`): a new academic-year curriculum, or a restructure that breaks links
- **MINOR** (`1.1.0`): new sessions, notebooks, projects or resources
- **PATCH** (`1.0.1`): fixes, typos, small clarifications

Release notes are drafted automatically from merged pull request titles. See the [maintainers guide](docs/maintainers-guide.md#releases).
